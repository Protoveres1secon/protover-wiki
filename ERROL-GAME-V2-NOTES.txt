PROTO VERES — SANS OMNI GOD ERROL: SOUL LOOP v2

BALANCE UPDATE
- Errol has exactly 1 HP. Any unblocked hit instantly ends the run. There is no passive HP regeneration.
- Chara has 480 HP (previously 180), enters phase 2 after falling below 66% HP, and attacks faster.
- Chara now rotates through 7 patterns: targeted slash, Soul Crash radial burst, Scarlet Fan, Triple Hunt, Scarlet Cross, Falling Souls, and Double Loop.
- Perfect Parry was fixed so it resolves before invulnerability checks. A successful parry reflects damage and restores mana.
- Soul Ward can absorb one hit before breaking. Dash grants a short evasion window.

CONTROLS (KEYBOARD)
- WASD / Arrow keys: Move
- J / Z: Eye I — Soul Strike
- K / X: Eye II — Fracture Step
- Q: Eye III — Erasure Lance (38 mana)
- E: Soul Ward (28 mana; blocks one hit)
- R: Soul Compass (30 mana; reflects nearby enemy projectiles, or launches a counter volley)
- F: EXO Verdict (requires 100 mana)
- Space / Shift: Dash
- L: Perfect Parry (timing matters)

MOBILE
Use the directional pad and action buttons underneath the game canvas. Touch the canvas to start/attack.

INSTALL INTO PROTOVERES MAIN WEB
1. Upload errol-game.html to the repository root.
2. Follow protoveres-game-integration.txt to add the 🎮 Game menu and embedded game view to index.html.
3. Commit and wait for GitHub Pages deployment before testing the public URL.

This is a web game prototype. The update files are not live on GitHub Pages until uploaded and committed.
