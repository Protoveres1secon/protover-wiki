# Protoveres Press — official launch package

This folder is intended to be placed at `press/` in the existing public repository `Protoveres1secon/protover-wiki`.

Public URL: https://protoveres1secon.github.io/protover-wiki/press/

The public site is English-first and has no language selector. Readers can use browser translation. The homepage is intentionally empty until the newsroom publishes real stories.

See `press/README.md` for article publishing instructions and technical limitations.
