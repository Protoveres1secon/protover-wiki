# Protoveres Press — Official GitHub Pages Edition

Public URL: https://protoveres1secon.github.io/protover-wiki/press/

English-first public newspaper. No language selector; readers may use their browser's built-in translation. Reading is free and does not require an account.

`articles.json` is intentionally empty until the newsroom publishes real stories. Add only public articles with `status: "published"`. Each record should contain `title`, `excerpt`, `category`, `date`, `image`, `imageAlt`, `url` and `status`. Keep article pages and media inside this `/press/` folder, then update `sitemap.xml`.

GitHub Pages is static hosting. The newsroom editor remains separate; publishing means exporting the static article files and committing them to the public repository. Never upload drafts, passwords, API keys or private data.
